# MSc Bioinformatics – Mathematics & Statistics Coursework

## 📘 Project Overview

This repository contains my completed coursework for the module “Essentials of Mathematics and Statistics”, undertaken as part of the MSc Bioinformatics programme at the University of Birmingham.

The project integrates mathematical reasoning, statistical theory, and computational implementation in R, demonstrating reproducible workflows, modular coding, and clear interpretation of statistical results.

- Coursework brief: STUDENT_cwork_MScBioinf-Dec-25.html  
- Final submission: coursework_shalini.html  
- Source analysis: coursework_shalini.Rmd

This coursework achieved a grade above 80%, reflecting strong performance in both conceptual understanding and computational implementation.
