# MSc Bioinformatics – Mathematics & Statistics Coursework

## 📘 Overview

This repository contains my completed coursework for the module **"Essentials of Mathematics and Statistics"** as part of the MSc Bioinformatics programme.

The coursework focuses on applying mathematical and statistical concepts using **R**, integrating theory with practical implementation. It demonstrates reproducible workflows, structured analysis, and custom function development.

## 🚀 Getting Started

### Prerequisites

Ensure you have the following installed:

- R (≥ 4.0)
- RStudio (recommended)
- Required R packages:

```r
install.packages(c("tidyverse", "ggplot2", "knitr", "rmarkdown"))
```

---

### ▶️ Running the Project

1. Clone the repository:

```bash
git clone https://github.com/<your-username>/msc-bioinformatics-math-stats-coursework.git
```

2. Open `coursework_shalini.Rmd` in RStudio

3. Ensure working directory is set correctly

4. Run or knit the file:

```r
rmarkdown::render("coursework_shalini.Rmd")
```
